## 🌟 Что реализовано для Telegram

### 1. Telegram Mini App (TMA Frontend)
- **Telegram WebApp SDK (`telegram-web-app.js`)**: автоматическая инициализация `Telegram.WebApp.ready()` и `expand()`.
- **Тактильный отклик (Haptic Feedback)**: вибрация при клике по табам, переключении категорий, добавлении в вишлист и открытии карточек.
- **Нативная кнопка «Назад» (Telegram BackButton)**: при открытии карточки выставки вверху слева в Telegram появляется нативная стрелочка возврата.
- **Персонализация**: отображение имени пользователя из Telegram (`tg.initDataUnsafe.user.first_name`).
- **Синхронизация через CloudStorage**: сохраненные выставки и вишлист синхронизируются в облаке Telegram между всеми устройствами.
- **Поделиться в Telegram**: кнопка «✈️ Поделиться событием в Telegram» в карточке каждой выставки для мгновенной пересылки друзьям в чаты.

### 2. Telegram Bot (`web_app/server.js`)
- **/start** — приветствие, кнопка запуска Mini App и интерактивное меню.
- **/expos** — карточки ближайших мировых конвентов (DesignerCon, WonFes, Pop Toy Show, STS, TTE, TTF) с кнопками быстрого перехода.
- **/drops** — радар эксклюзивных и редких арт-релизов (Grail Radar) с тиражами и ценами.
- **/cities** — путеводитель по мировым столицам арт-тоя (Токио, Шанхай, Бангкок, Лос-Анджелес).
- **/help** — справка по командам.
- **Inline Callback Buttons**: интерактивные кнопки внутри чата без необходимости печатать команды вручную.
- **Авто-настройка кнопки меню**: бот автоматически регистрирует постоянную кнопку **"ToyExpo 👾"** внизу экрана ввода сообщений через `setChatMenuButton`.

## 🛠️ Инструкция: как подключить своего бота за 2 минуты

### Шаг 1: Создайте бота в Telegram
1. Откройте в Telegram официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Введите название (например: `ToyExpo Guide`) и юзернейм бота (например: `toy_expo_test_bot`).
4. Скопируйте полученный **HTTP API Token** (вида `123456789:AAFx...`).

### Шаг 2: Создайте Mini App команду в @BotFather
1. В том же диалоге с **[@BotFather](https://t.me/BotFather)** отправьте:
   ```text
   /newapp
   ```
2. Выберите вашего созданного бота.
3. Введите название приложения: `ToyExpo`.
4. Введите краткое описание: `Календарь выставок дизайнерских игрушек, софуби и эксклюзивных релизов`.
5. Загрузите иконку (640x360 пикселей) или отправьте `/empty`.
6. На шаге ввода **URL** отправьте:
   ```text
   https://ais-dev-j26bpgydmt66pujpm56vsi-851278613227.asia-east1.run.app
   ```
7. Придумайте короткое имя (short name), например: `app` или `expo`.
8. Готово! Вы получите прямую ссылку вида: `t.me/your_bot_username/app`.

### Шаг 3: Настройте кнопку меню бота (Menu Button)
Чтобы в боте слева от поля ввода всегда была кнопка открытия Mini App:
1. В **[@BotFather](https://t.me/BotFather)** отправьте:
   ```text
   /setmenubutton
   ```
2. Выберите вашего бота.
3. Отправьте ссылку:
   ```text
   https://ais-dev-j26bpgydmt66pujpm56vsi-851278613227.asia-east1.run.app
   ```
4. Введите текст для кнопки: `ToyExpo 👾`.

### Шаг 4: Запуск бота
Чтобы бот отвечал на текстовые команды в чате Telegram:
```bash
cd web_app
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ИЗ_BOTFATHER"
node server.js
```

## 🌐 Деплой на бесплатный хостинг (Vercel / Render / Railway)
Папка `web_app/` полностью самодостаточна:
- Содержит `package.json`, `server.js`, статику в `public/` (HTML, PWA-манифест, иконки).
- Для Vercel / Cloudflare Pages достаточно просто задеплоить папку `web_app/public` (статический сайт).
- Для Render / Railway / Amvera / VPS запускается команда `npm start` с переменной окружения `TELEGRAM_BOT_TOKEN`.
